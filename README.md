# My First GitHub Repo

A simple blog website built with HTML and CSS.

## Features

- Responsive design
- Clean and modern UI
- Gradient header
- Blog post cards with shadows

## Technologies Used

- HTML5
- CSS3

## How to View

1. Clone the repository:
```bash
git clone https://github.com/Jewel-190237/my-first-github-repo.git
cd my-first-github-repo
```

2. Open `index.html` in your browser
